# Enum Builder
Автор лабораторной работы: Яковлев Никита Алексеевич, M3115.

Расширение настольного VS Code на JavaScript. Генерирует C++11 enum class с базовым типом std::int32_t и функцию toString со switch и веткой Unknown.

## Возможности
Ввод: `Status: New, Active=5, Done`. Результат: New=0, Active=5, Done=6. Значение без числа вычисляется как предыдущее + 1; первое по умолчанию равно 0. Поддерживаются отрицательные десятичные числа. Проверяются формат, пустые элементы, имена, ключевые слова, дубли имён и значений, диапазон int32. Имена ограничены латинской буквой в начале, латинскими буквами, цифрами и подчёркиваниями далее; двойные подчёркивания запрещены. Длина ввода не больше 5000 символов. Дроби, выражения и шестнадцатеричные числа не поддерживаются.

Команда и кнопка Enum Builder открывают форму. Результат можно скопировать или открыть в новом несохранённом C++ документе. После правки ввода кнопки результата блокируются до новой генерации. Исходные файлы не перезаписываются. Компиляция C++ не выполняется самим плагином.

## Запуск
Откройте эту папку в VS Code → Run → Start Debugging → Run Enum Builder. Во втором окне нажмите Enum Builder внизу или Cmd+Shift+P → Enum Builder: Открыть генератор. Отдельная установка Node.js и npm install для демонстрации не нужны.
