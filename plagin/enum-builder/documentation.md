# Архитектура и функции
Манифест package.json объявляет команду enumBuilder.open, точку входа extension.js и событие onStartupFinished, чтобы кнопка появилась после запуска. JavaScript выполняется в Extension Host VS Code. Webview содержит HTML-форму и взаимодействует с расширением через postMessage.

Поток: ввод → сообщение generate → generate(input) → проверка → массив items → генерация C++ → сообщение с кодом либо ошибкой → форма.

## core.js
checkName(name) проверяет ограниченный формат идентификатора и Set ключевых слов C++20. При ошибке бросает Error.
generate(input) принимает строку и возвращает C++ код. Разделяет описание по двоеточию и запятым. Для каждого элемента выделяет имя и необязательное число. Множества names и values обеспечивают поиск дублей, массив items хранит объекты {name,value}, переменная next хранит следующее автоматическое значение. Ошибки останавливают генерацию. Дубли чисел запрещены, потому что создаваемый switch не допускает одинаковые case. После значения INT32_MAX следующий автоматический элемент вызывает ошибку; явно заданное другое допустимое число разрешено.

Для длины ввода L и числа элементов N ожидаемое время O(L+N), память O(L+N). Генератор — не C++ парсер общего назначения. Строго ограниченная грамматика нужна, чтобы код оставался небольшим и предсказуемым.

## extension.js
activate(context) создаёт кнопку в строке состояния и регистрирует команду. При вызове создаётся Webview. Обработчик сообщений выполняет generate, copy или open. Ошибки перехватываются try/catch и передаются в форму; старый результат сбрасывается перед обработкой нового ввода. copy использует vscode.env.clipboard, open создаёт несохранённый документ language: cpp. Все изменения пользовательского ввода выводятся через textContent, HTML из ввода не исполняется. CSP разрешает только скрипт и стиль с nonce. Ресурсы очищаются через subscriptions и onDidDispose.
html(nonce) возвращает разметку формы с полем, тремя кнопками, результатом и ошибкой.
