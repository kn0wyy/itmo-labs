Проверка функций площади и периметра круга, квадрата, прямоугольника и треугольника. 32 теста стандартного модуля Python `unittest`, четыре класса `TestCase`.

## Запуск

Откройте именно папку `lab04-unit-tests` в VS Code. В меню Terminal → New Terminal выполните:

```sh
python3 --version
python3 -m unittest discover -s tests -v
```

Python 3 должен быть установлен. Дополнительные библиотеки и `pip install` не нужны: unittest входит в Python. Проверено на Python 3.12.14.

Отдельная фигура:

```sh
python3 -m unittest tests.test_rectangle -v
```

Ручное сравнение результатов:

```sh
python3 manual_check.py
```

## Что проверяется

В каждом модуле проверяются обе функции: целые положительные числа, дробные значения и особые случаи. Нулевые размеры проверяются как граничный случай вычисления формул, а не как полноценная геометрическая фигура. Стороны треугольников в проверках периметра удовлетворяют неравенству треугольника.

Используется `assertAlmostEqual(..., places=7)`: результат сравнивается с независимым ожидаемым значением с учётом округления дробей. Круг сравнивается с числом π из стандартного `math`.

Валидация отрицательных размеров, строк и геометрически невозможных треугольников не входит в контракт проверяемых формул. Эти возможности исходная библиотека не реализует; тесты не добавляют их и не изменяют исходники. Производительность, безопасность и графический интерфейс в эту работу не входят.
